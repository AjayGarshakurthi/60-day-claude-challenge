# DAY 08-Environmental Health Analyzer Dashboard

## Overview
This project is an interactive Environmental Health Analyzer dashboard generated using Claude AI. The dashboard helps visualize environmental health metrics through charts, graphs, and filters, enabling users to explore air quality and pollution-related data effectively.

## Features
- Interactive dashboard interface
- Environmental health data visualization
- Dynamic charts and graphs
- Filtering and data exploration
- Responsive HTML application
- User-friendly design

## Technologies Used
- HTML
- CSS
- JavaScript
- Claude AI (for dashboard generation)

## Learning Outcomes
- Understanding AI-assisted dashboard development
- Building interactive data visualization tools
- Working with HTML-based applications
- Testing and documenting AI-generated projects
