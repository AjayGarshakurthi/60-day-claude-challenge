# 🚀 30-Day Learning Roadmaps – Web Development vs Tech Job Preparation

## 📌 Overview
This document compares two structured 30-day learning roadmaps:

1. **Web Development Beginner Roadmap** (Skill-building focused)
2. **Tech Job Preparation Roadmap** (Career/interview focused)

Both paths are designed for beginners but target completely different outcomes.

---

# 🌐 Roadmap 1: 30-Day Web Development Learning Path

## 🎯 Goal
Build strong **frontend development skills** through hands-on projects and real coding practice.

## ⏱️ Time Commitment
- 3+ hours per day
- Project-based learning

---

## 🧱 Week 1: HTML Foundations
**Milestone:** Build a personal webpage

- Day 1: Setup VS Code + HTML basics
- Day 2: Text structure (headings, paragraphs, lists)
- Day 3: Images, links, multi-page site
- Day 4: Tables and forms
- Day 5: Semantic HTML (header, footer, section)
- Day 6–7: Personal homepage project + GitHub Pages

---

## 🎨 Week 2: CSS Styling
- CSS basics (selectors, colors, fonts)
- Box model and spacing
- Flexbox layout
- Responsive design basics
- Mini project: Styled portfolio page

---

## ⚙️ Week 3: JavaScript Basics
- Variables, loops, functions
- DOM manipulation
- Events and interactivity
- Simple browser projects
- Mini project: Interactive webpage

---

## 🚀 Week 4: Projects & Deployment
- Build small real-world projects
- Improve UI/UX design
- Git & GitHub workflow
- Deploy projects (GitHub Pages / Vercel)

---

## 🏁 Outcome
- 4+ mini projects
- Personal portfolio website
- GitHub deployment experience
- Strong frontend fundamentals

---

# 💼 Roadmap 2: 30-Day Tech Job Preparation Path

## 🎯 Goal
Become **job-ready for tech interviews** with strong problem-solving and system thinking skills.

## ⏱️ Time Commitment
- ~5 hours per day

---

## 🧠 Week 1: DSA Foundations
- Arrays & Strings
- Recursion basics
- Basic problem-solving patterns
- Python practice

---

## 🌳 Week 2: Intermediate DSA + System Thinking
- Trees & Graphs
- Dynamic Programming intro
- Time complexity analysis
- System design basics

---

## 🔧 Week 3: Specialization + Resume Project
- Choose domain (IoT / Software / Backend / etc.)
- Build resume-worthy project
- Improve GitHub profile
- Start LinkedIn optimization

---

## 🎤 Week 4: Interview Preparation
- Mock interviews
- Problem-solving revision
- Resume polishing
- Job applications
- LinkedIn networking

---

## 🏁 Outcome
- Strong DSA foundation
- Interview readiness
- Resume + LinkedIn profile
- Job application preparation

---

# ⚖️ Key Comparison

| Feature | Web Dev Roadmap | Job Prep Roadmap |
|----------|----------------|------------------|
| Focus | Building skills | Getting hired |
| Core Area | Frontend Dev | DSA + Interviews |
| Output | Projects | Job readiness |
| Learning Style | Practical + creative | Analytical + problem-solving |

---

# 💡 Key Insight

- Web Dev roadmap = **Build things**
- Job Prep roadmap = **Solve problems to get selected**

Both are powerful, but serve different goals.

---

# 🔥 Final Thought

The best growth comes when you:
- Learn consistently
- Build real projects
- And align learning with your career goal
